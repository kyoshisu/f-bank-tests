# БАГ-РЕПОРТ №2

## Заголовок
Поле ввода суммы перевода принимает отрицательные значения

## Приоритет
High

## Серьёзность
Critical

## Окружение
- Браузер: Chrome 120+
- URL: http://localhost:8000/?balance=30000&reserved=0

## Шаги воспроизведения
1. Открыть страницу F-Bank
2. Кликнуть на карточку "Рубли"
3. В поле ввода суммы перевода ввести "-30001"

## Ожидаемый результат
Поле не должно принимать отрицательные числа

## Фактический результат
Отрицательное значение принимается и отображается

## Дополнительная информация
Это может привести к некорректному отображению данных
